# Jingle Dash

Jingle Dash is a Christmas-themed 3D endless runner that runs in the browser from one self-contained HTML file. three.js is bundled inside, and all models, music and sound effects are generated in code, so the game makes no network requests while you play.

Pick one of four runners, each with its own perk: Santa (extra heart), Elf (higher jump), Reindeer (double jump) or Penguin (longer candy magnet). Switch lanes, jump over snowmen, ice and fences, and collect candy canes and presents to fill your stocking for extra hearts. Watch for red rings on the road: the Coal Goblin throws hot coal there. The game gets faster the longer you run.

Controls: arrow keys or A/D to change lane, Space or ↑ to jump, ↓ to drop, P to pause. On touch screens, swipe or use the on-screen buttons.
